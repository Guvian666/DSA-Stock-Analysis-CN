一、它是什么

一个跑在你自己电脑上的股票分析工具。你给它股票代码，它去拉行情、K 线、技术指标、公告与新闻，然后让大模型写出一份「决策仪表盘」：核心结论、评分、趋势判断、买卖点位、风险提醒、催化因素、操作检查清单。

三点要说清楚：

  • 本地运行：界面和后端都在你电脑上，行情与报告不经过第三方服务器（只有调用大模型时会联网）。
  • 它是助手，不是操盘手：只做分析与提示，不会替你下单、不会接券商账户自动交易。
  • 模型可选：用哪家大模型由你决定，也可以接本地模型完全离线跑（除行情外）。

系统Windows 10 / 11，64 位

四、安装与首次启动

1. 运行安装包：双击 DSA-股票智能分析-v3.35.0-安装包.exe。

2. 选择安装位置：默认装在当前用户目录（不需要管理员权限）。可以改到 D 盘等非系统盘，但不要选 C:\Program Files、C:\Windows 这类受保护目录。

3. 完成安装：勾选「创建桌面快捷方式」后，桌面会出现「股票智能分析」图标，开始菜单同目录也有一份。

首次双击启动时，窗口会先显示一个启动页：

股票智能分析
正在启动本地分析服务
正在准备后端并加载界面…

这一步需要 10~20 秒（后端要初始化数据库、加载策略与行情源）。期间看起来像卡住是正常现象，请不要反复点关闭。加载完成后会自动进入主界面。

不要关掉的进程：桌面版是「外壳 + 后台服务」两层，后台服务随外壳一起启动/退出。 关掉主窗口等于结束整个程序；分析任务会中断。想让它长期常驻（比如配合定时任务），就别关窗口，也别让电脑睡眠。

五、三步完成配置（必做）

刚装好时，程序能打开、能看界面，但点「分析」会报错——因为它还没有大模型。三步补齐即可。

第 1 步：配置大模型（唯一必填项）

进入 系统设置 → AI 模型 / LLM 渠道，选一个服务商填 Key。最省事的是 DeepSeek（国内直连、按量付费、单价很低）：

  1. 打开 platform.deepseek.com，注册并创建 API Key（sk- 开头）。
  2. 在设置页选择 DeepSeek，把 Key 粘进去，模型填 deepseek-v4-flash。
  3. 点保存，再点测试渠道，看到「通过 / succeeded」就说明通了。

也支持其他方式：

  • 任意 OpenAI 兼容接口（中转站、自建网关、通义、Kimi 等）：填 Base URL + Key + 模型名即可。
  • 本地模型：装好 Ollama 并拉一个模型，渠道选 Ollama，地址 http://localhost:11434，无需 Key、零成本。

第 2 步：填自选股

系统设置 → 基础配置 → 自选股，按 600519,000001,hk00700,AAPL 这种格式填，逗号分隔。也可以在首页搜索框里逐只添加。

第 3 步（建议）：补一个新闻搜索源

不配也能跑，但报告里的「舆情 / 公告 / 催化因素」会是空的，因为程序没有搜新闻的能力。配一个即可，比如 Tavily、博查（Bocha）、SerpAPI 或 Brave 的 Key。自建 SearXNG 也可以。

判断是否配好了：打开「系统设置」，看体检清单。所有必填项都变绿（主渠道、自选股、数据库），就可以开始分析了。

六、怎么做一次分析

1. 首页搜索框输入股票代码或名称（支持拼音首字母，如 dfjm → 东方精工），选中目标。

2. 点「开始分析」。任务会进入队列，右侧能看到进度条（0→100）。

3. 等待 1~3 分钟（取决于行情源速度与模型响应）。期间可以做别的事，进度会持续刷新。

4. 完成后自动跳到报告页，同时写入历史报告。报告可以复制、导出 Markdown、发到通知渠道。

几个实用操作：

  • 批量分析：在分析页可以一次勾选多只，程序按并发上限（默认 3）排队跑。
  • 强制刷新：勾上「强制刷新」会忽略缓存，重新抓全部数据；不勾则优先用库里已有数据，速度快很多。
  • 大盘复盘：单独一个入口，输出指数、涨跌家数、板块领涨领跌，不发个股报告。
  • 看历史：「历史报告」按时间倒序列出所有做过的分析，点进去看完整 Markdown 原文。

七、报告怎么看

字段含义使用建议
综合评分 0–100，模型对当前技术面与消息面的整体打分 只是参考刻度，不是买入阈值。60 分以上通常偏正面，40 以下偏负面
趋势判断 看多 / 震荡 / 看空 跟均线排列、量能配合一起看，别单独依赖
操作建议 买入 / 观望 / 卖出 / 减仓 / 持有 结合你自己的成本位和仓位，报告不知道你的持仓成本
买卖点位 模型给出的参考支撑、压力、止损位 当作纪律线用：跌破就按纪律办，而不是找理由改线
风险警报 资金流出、筹码集中度过高、违规记录、解禁等 这一栏往往比结论更有价值，逐条看
利好催化 业绩预增、订单、政策、行业景气等 注意区分「已兑现」与「预期」，前者常已price in
操作检查清单 下单前该确认的事项 照着过一遍，能挡掉不少冲动交易
报告里出现「新闻/筹码/财报数据缺失」不是模型偷懒，而是对应数据源没配或没抓到时，模型的诚实声明。 这类报告的结论应当降权看待。

八、策略问股（进阶）

报告是一次性的，问股是对话式的。进入 策略问股 页面，选一个策略（如「均线金叉」「缠论」「热点题材」），然后像聊天一样追问：

这只票现在符合你选的策略吗？
如果我按你说的止损位挂单，风险有多大？
换成同板块的另一只，哪个位置更好？

它支持多轮上下文、可导出会话、可把结论发到通知渠道。问股用的模型默认继承主渠道，也可以在设置里单独指定一个更便宜的模型。

九、自动分析与推送（可选）

不想每天手动点，可以让它自己跑：

  1. 系统设置 → 通知渠道：配一个推送出口。企业微信群机器人最简单（填 Webhook URL 即可），邮件需要发件邮箱与授权码。
  2. 系统设置 → 定时任务：设置每天的运行时间（如工作日 18:00）。
  3. 前提是程序得在运行——桌面版关掉窗口就停了。要长期无人值守，建议用本目录里的浏览器版启动脚本配合 Windows 任务计划，或干脆放到一台常开的小主机上。

十、数据源与能力边界

项目说明
默认行情源 AkShare、Baostock、YFinance 等免费源，零配置可用。但免费源受上游限流与接口变动影响，稳定性不保证
更稳的方案 配置 Tushare（A 股）、TickPlus（A 股/ETF）、Longbridge（港美股）等 token 型数据源
抓不到数据的典型表现 日志里出现 RemoteDisconnected、Max retries exceeded；分析变慢或降级
实时性 免费源通常是延迟行情，不要拿它当分时做 T 的决策依据
模型能力边界 模型不掌握你的成本、仓位、资金计划；也不了解你的风险偏好。这些必须你自己加进去

十一、常见故障排查

现象原因与处理
启动页停很久（20 秒以上） 多为网络慢：程序在等行情源和模型价格表。断网也能起，但会慢。反复卡死再查安装目录 logs\desktop.log
点分析报「LLM API Key 未配置」 模型 Key 没填或没保存。回设置页确认「测试渠道」通过
提示端口 8000 被占用 已有一份在跑。桌面版会自动改用 8000–8100 之间的空闲端口；浏览器版需要先关掉占用者
界面是英文 点界面上的 EN / 中 语言切换按钮。语言选择记在本地，换台电脑默认中文
报告里新闻、公告全是空的 没配搜索源。设置页补一个 Tavily / Bocha / SerpAPI
分析到一半失败 看历史报告详情里的错误信息；常见是行情源全挂或模型超时。重试一次，仍失败就换数据源或换模型
报告存在哪 安装目录下的 data\stock_analysis.db（历史记录）与 resources\backend\stock_analysis\_internal\reports\（Markdown 原文）

十二、卸载与数据

  • 卸载：Windows「设置 → 应用 → 已安装的应用」里找到「DSA 股票智能分析」，点卸载。
  • 数据默认保留：卸载不会删掉 data、logs 与 .env，重装后历史报告还在。要彻底清干净需手动删除安装目录。
  • 迁移：把整个安装目录复制到新机器即可带走配置与历史（模型 Key 在 .env 里，是明文，复制前想清楚）。
